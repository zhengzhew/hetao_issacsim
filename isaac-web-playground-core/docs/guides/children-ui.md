# 儿童交互界面

2026-09-16：根据提供的绿色学习应用参考图，使用薄荷绿背景、白色圆角卡片、草绿色主按钮，以及浅黄、浅蓝和紫色的场景插图。保留 NVIDIA 英伟达和 Isaac Sim 的名称及仿真说明。

## 使用流程

1. 选世界：四张带插图的场景卡片。
2. 选伙伴：保留 NVIDIA 机器人名称，增加简短中文能力说明。
3. 出发探索：图形方向按钮、按住移动与松开停止、独立红色停止按钮。

小芽机器人提供状态表情、步骤引导和点击反馈。语音优先播放随网页提供的 17 段中文 WAV；浏览器通常要求第一次点击后才允许有声播放，用户可点击“听一听”或开关声音。未预制的自定义内容使用浏览器语音能力，文字引导始终保留。`scripts/generate-child-voices.ps1` 使用 Windows 已安装的 Microsoft Huihui Desktop 语音重新生成资源，需用 Windows PowerShell 运行。

## 家长入口

参数、上传、模型助手、串流切换及技术诊断集中在家长工作台，先完成随机算术验证。关闭、离开可见页面或三分钟到期后重新锁定。外链点击同样经过验证。没有增加充值功能。

此闸门用于儿童交互防误触，不是服务端账户认证；原服务仍只适合可信网络。机器人控制接口、资源格式和仿真行为继续由原服务实现。

## 已执行验证

- 主服务浏览器：场景卡片、选择下一步、离线状态、家长验证错误拦截与正确进入工作台。
- 390×844 视口：页面宽度为 390，没有横向溢出，可见按钮高度均不小于 48px。
- 中文引导：浏览器音频元素播放 `welcome.wav` 并正常结束，时长约 6.13 秒，无媒体错误。
- 独立演示端口 18081：完成场景选择、伙伴选择、启动、模式切换与方向/停止请求，停止后服务返回各方向速度为零。测试不等于真实 Isaac Sim 运动验证。
- 桌面截图：停止按钮位于首屏；移动端采用底部固定停止操作区。
- Node.js 语法检查和 Git diff 空白检查通过。

真实 Isaac Sim 后续验收：四组场景/机器人通过加载与图像响应检查，Jetbot 前进与 Kaya 横移测得实际位姿变化；浏览器已显示 Grid/Jetbot 真实画面，并验证选择、启动、方向点击及停止反馈。外部设备局域网访问尚待确认。演示服务使用 18765/49110/18081 端口，避免占用真实桥接的 8765 端口。
